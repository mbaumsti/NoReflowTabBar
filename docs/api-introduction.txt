NoReflowTabBar API Reference

NoReflowTabBar is a Delphi VCL component providing a stable no-reflow tab and button bar with multi-row layout, logical zones, signals, inline editing, drag and drop, GDI/Direct2D rendering and layout persistence.

Version 1.3 introduces the stabilized Direct2D rendering backend and documents the shared layout/rendering contract. The layout/support layer prepares final positions, rectangles and render-item data; GDI and Direct2D consume those data and draw them.

This public API reference is generated from the Pascal source comments.

Recommended reading order:
- TNoReflowTabBar
- TNoReflowTabBarItem and TNoReflowTabBarItems
- TNoReflowTabBarMode
- TNoReflowTabBarPosition
- TNoReflowTabBarRenderBackendKind
- TNoReflowTabBarLayout and related layout classes
- TNoReflowTabBarStorageOptions
- NoReflowTabBar_CaptionEditor for inline editor extension points

This public reference intentionally focuses on the units normally useful to application developers, including the public caption editor abstraction used by optional adapters.
