NoReflowTabBar API Reference

NoReflowTabBar is a Delphi VCL component providing a stable no-reflow tab and button bar with multi-row layout, logical zones, signals, inline editing, drag and drop, custom rendering and layout persistence.

This public API reference is generated from the Pascal source comments.

Recommended reading order:
- TNoReflowTabBar
- TNoReflowTabBarItem and TNoReflowTabBarItems
- TNoReflowTabBarMode
- TNoReflowTabBarPosition
- TNoReflowTabBarLayout and related layout classes
- TNoReflowTabBarStorageOptions
- NoReflowTabBar_CaptionEditor for inline editor extension points

This public reference intentionally focuses on the units normally useful to application developers, including the public caption editor abstraction used by optional adapters.
