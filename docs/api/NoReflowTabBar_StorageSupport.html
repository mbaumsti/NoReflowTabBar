Types

TNoReflowTabBarStoragePart = (...);

Defines which parts of each item can be saved and restored.

The selected parts are used together with TNoReflowTabBarStorageOptions to decide which properties are exported to or imported from storage.

Values
  • nrbspPlacement
  • nrbspCaption: Zone and ZoneIndex.
  • nrbspVisibility: Caption.
  • nrbspEnabled: Visible.
  • nrbspSignal: Enabled.
  • nrbspHint: SignalCode, SignalValue and SignalMax.
  • nrbspGlyph: Simple glyph-related item properties.

    This part stores lightweight persistent properties only: - ShowGlyph; - GlyphIndex; - GlyphPosition.

    It intentionally does not serialise an embedded bitmap glyph. Bitmap glyph persistence requires a dedicated storage strategy and should not be mixed with this generic logical storage layer.

  • nrbspChecked: Persistent Checked state carried by the item model.

    This is primarily useful in nrbmCheckButtons mode, but it is kept as an independent state so storage can accurately preserve the model.

  • nrbspSelection

TNoReflowTabBarStorageRestoreMode = (...);

Defines how stored data is applied during restoration.

nrbsmApplyExistingOnly updates only items already present in the bar. nrbsmCreateMissing creates missing items when enough identity data is available in storage. nrbsmReplaceAll replaces the items in the selected storage zones.

Values
  • nrbsmApplyExistingOnly
  • nrbsmCreateMissing
  • nrbsmReplaceAll
TNoReflowTabBarStorageValueKind = (...);

Logical value type stored in a TNoReflowTabBarStorageEntry.

A final backend may use this information or ignore it. For example, an INI file can store everything as text, while a registry or database backend can use the kind to choose a native value type.

Values
  • nrbsvkString
  • nrbsvkInteger
  • nrbsvkBoolean
  • nrbsvkFloat
