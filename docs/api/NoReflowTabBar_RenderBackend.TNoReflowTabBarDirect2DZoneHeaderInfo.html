type TNoReflowTabBarDirect2DZoneHeaderInfo = record

Description

Donnees resolues d'un header de zone pour un backend separe.

Depuis v71, le header est calcule par la couche layout du composant, car il depend de la zone logique, de la position de barre, du mode de placement du header et de la transformation canonique du moteur de zones. Le backend Direct2D recoit uniquement les primitives finales : segments, point d'ancrage du texte, metriques et police.
