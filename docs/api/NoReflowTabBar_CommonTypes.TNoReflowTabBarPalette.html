Unit

NoReflowTabBar_CommonTypes

type TNoReflowTabBarPalette = record

Description

Palette complète utilisée au moment du dessin.

Cette structure est la forme résolue des couleurs réellement utilisées par le moteur de rendu, quel que soit le mode choisi (custom ou style).

Public TabPressedTop: TColor;

Couleurs du mode onglets : état pressé.

Même si l'état pressé est moins central pour un onglet classique que pour un bouton, il existe dans le pipeline visuel du composant. Le garder explicitement évite de rabattre artificiellement Pressed sur Hot, ce qui devient faux en mode style.
