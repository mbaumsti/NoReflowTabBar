NoReflowTabBar_Items

Declaration

type INoReflowTabBarModelHost = interface(IInterface)

Description

Minimal host interface exposed by the owning component to the item model.

The model classes use this interface instead of depending directly on TNoReflowTabBar. This keeps the item model independent from the final visual control and avoids circular dependencies between units.
