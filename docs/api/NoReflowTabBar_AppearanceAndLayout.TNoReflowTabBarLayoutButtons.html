Declaration

type TNoReflowTabBarLayoutButtons = class(TPersistent)

Description

Layout settings specific to button rendering.

This class contains only button-specific properties: - spacing between independent buttons; - optional forced dimensions; - optional minimum button length when the length is not forced; - corner radius; - border drawing; - visual pressed-content offset.

Common text, signal, glyph and margin settings remain in TNoReflowTabBarLayout.

Public property OnChanged: TNoReflowTabBarObjectChangedEvent Read FOnChanged Write FOnChanged;

Event fired when a button-layout property changes.

Published property ButtonSpacing: Integer Read FButtonSpacing Write SetButtonSpacing default 6;

Spacing between two consecutive buttons.

Unlike TabOverlap, this is a normal positive spacing between independent button shapes.

Published property ForcedLength: Integer Read FForcedLength Write SetForcedLength default 0;

Forced button length in the item flow direction.

This is a logical dimension, not necessarily the physical screen width. A value of 0 means that the natural length is computed from the item content.

Published property MinimumLength: Integer Read FMinimumLength Write SetMinimumLength default 0;

Minimum button length in the item flow direction.

This property is used only when ForcedLength is 0. The natural length is still computed from the item content, then raised to this minimum when necessary. A value of 0 disables the minimum constraint.

Published property ForcedThickness: Integer Read FForcedThickness Write SetForcedThickness default 0;

Forced button thickness in the item cross direction.

This is a logical dimension, not necessarily the physical screen height. A value of 0 means that the natural thickness is computed from the item content.

Published property CornerRadius: Integer Read FCornerRadius Write SetCornerRadius default 3;

Button corner radius.

Published property DrawBorder: Boolean Read FDrawBorder Write SetDrawBorder default True;

Controls whether a border is drawn around buttons.

Published property PressedOffset: Integer Read FPressedOffset Write SetPressedOffset default 1;

Visual content offset applied when a button is pressed.

A value of 0 disables the offset.
