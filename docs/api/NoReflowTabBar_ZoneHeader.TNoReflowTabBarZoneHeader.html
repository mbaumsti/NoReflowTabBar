NoReflowTabBar_ZoneHeader

Declaration

type TNoReflowTabBarZoneHeader = class(TPersistent)

Description

Persistent configuration object describing decorative zone headers.

A zone header can display separate captions for the Start, Center and End logical zones. The object stores only configuration data: visibility, captions, font, margins, dimensions, placement and colors.

Actual layout computation and drawing are handled by the specialised layout and rendering layers of the component.

Protected Function GetOwner: TPersistent; Override;

Returns the persistent owner of the zone-header configuration object.

This allows the Object Inspector and streaming system to associate the sub-object with its owning component.

Public Constructor Create(AOwner: TPersistent);

Creates the zone-header configuration object and stores its owner.

Public Destructor Destroy; Override;

Releases the owned font object.

Public Procedure Assign(Source: TPersistent); Override;

Copies all zone-header settings from another compatible persistent object.

Public Function HasAnyCaption: Boolean;

Returns True when at least one of the Start, Center or End captions is not empty.

Public Function GetTotalHeight: Integer;

Returns the total vertical size consumed by the zone header.

The result is 0 when the header is not visible or when all captions are empty. Otherwise it includes the configured top margin, header height and bottom margin.

Public property OnChanged: TNotifyEvent Read FOnChanged Write FOnChanged;

Event fired when any setting changes.

The owning control uses this notification to invalidate layout and/or repaint itself without the configuration object depending directly on the final component class.

Published property Visible: Boolean Read FVisible Write SetVisible Default False;

Published property Placement: TNoReflowZoneHeaderPlacement Read FPlacement Write SetPlacement Default nrthpOuterBand;

Defines where the zone header is placed relative to the bar content.

nrthpOuterBand reserves a dedicated band outside the item area. nrthpAboveZone draws the header above its zone within the zone layout context.
