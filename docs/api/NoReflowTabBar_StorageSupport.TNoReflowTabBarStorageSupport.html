NoReflowTabBar_StorageSupport

Declaration

type TNoReflowTabBarStorageSupport = class(TNoReflowTabBarDragSupport)

Description

Storage support layer of the NoReflowTabBar component.

This class exposes backend-independent save and restore operations. It produces and consumes logical storage entries, then provides convenience wrappers for TStrings, UTF-8 streams, files and INI files.

The class intentionally depends on no application-specific storage system.
