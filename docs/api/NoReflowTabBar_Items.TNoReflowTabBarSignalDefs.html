type TNoReflowTabBarSignalDefs = class(TOwnedCollection)

Description

Collection of signal definitions available to one bar.

The collection is owned by TNoReflowTabBar and is used to provide built-in status indicators, add user-defined indicators, and resolve indicators by code or name.
