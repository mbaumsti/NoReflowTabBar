Declaration

type TNoReflowTabBarItem = class(TCollectionItem)

Description

Persistent logical item stored in a NoReflowTabBar item collection.

This class contains no geometry and no rendering logic. It describes the item data: caption, visibility, enabled state, checked state, signal, user identifier, hint, logical zone and optional glyph information.

Properties

Public property Host: INoReflowTabBarModelHost Read GetHost;

Host interface of the owning collection.

Public property ItemIndex: Integer Read GetItemIndex;

Current absolute index of the item in its collection.

The value is computed on demand from the owning collection.

Public property ItemKey: Integer Read FItemKey;

Unique technical item key.

This key is generated automatically by the collection and is used for stable identification during persistence, restoration and internal operations that must not depend on the current collection index.

Unlike UserId, this key has no business meaning and should not be modified by application code.

Public property PinZone: TNoReflowTabBarPinZone Read FPinZone Write SetPinZone default nrtpzCenter;

Internal logical pin zone of the item.

This property is kept for component internals and is normalized to one of the effective zones: nrtpzStart, nrtpzCenter or nrtpzEnd.

Public property Data: TObject Read FData Write FData;

Free user object associated with the item.

The tab bar does not own this object. The caller remains responsible for its lifetime.

Public property GlyphName: String Read FGlyphName Write SetGlyphName;

Optional symbolic glyph name.

This property is reserved for a future name-based glyph resolution mechanism. It is available to application code, but is not published because it is not currently an active design-time feature.

Published property Caption: String Read FCaption Write SetCaption;

Text displayed by the item.

Published property SignalCode: Integer Read FSignalCode Write SetSignalCode default 0;

Technical code of the signal used by the item.

The value 0 means that the item has no signal.

Published property SignalName: String Read GetSignalName Write SetSignalName stored False;

Name of the signal used by the item.

This is a convenience view over SignalCode. It does not store any additional state. Reading the property returns the name matching the current code. Writing the property searches a signal with that name and updates SignalCode automatically.

Published property SignalValue: Double Read FSignalValue Write SetSignalValue;

Current signal fill value.

This value is meaningful only when SignalMax is greater than 0. Otherwise the signal is drawn as a full indicator.

Published property SignalMax: Double Read FSignalMax Write SetSignalMax;

Maximum reference value for partial signal rendering.

Examples: - SignalValue = 3 and SignalMax = 4 means 75 percent filled; - SignalValue = 75 and SignalMax = 100 means 75 percent filled.

When SignalMax is less than or equal to 0, the signal is drawn as a full indicator.

Published property UserId: Integer Read FItemUserId Write SetItemUserId default 0;

User-defined item identifier.

This can be used to find or manipulate an item independently from its current collection index.

Published property KeyView: Integer Read FItemKey stored False;

Read-only design-time view of the internal technical key.

The real persistence of the technical key is handled through DefineProperties; this property only makes the generated key visible for diagnostics in the Object Inspector.

Published property Visible: Boolean Read FVisible Write SetVisible default True;

Indicates whether the item participates in layout, rendering and hit testing.

Published property Enabled: Boolean Read FEnabled Write SetEnabled default True;

Indicates whether the item can be selected or activated.

Published property Checked: Boolean Read FChecked Write SetChecked default False;

Indicates whether the item is checked.

The exact meaning depends on the bar mode: - tabs and single-selection buttons synchronize it with the active item; - check buttons use it as the independent state of each item; - push buttons do not automatically modify it when clicked.

Published property Hint: String Read FHint Write SetHint;

Item-specific hint text.

When this is empty, the component may fall back to the item caption.

Published property ShowHint: Boolean Read FShowHint Write SetShowHint default True;

Enables or disables hint display for this item.

Published property Zone: TNoReflowTabBarZone Read GetZone Write SetZone default nrtzCenter;

User-facing logical zone of the item.

nrtzStart keeps the item in the start block, nrtzCenter stores it in the regular center block, and nrtzEnd keeps it in the end block.

Published property ZoneIndex: Integer Read FZoneIndex Write SetZoneIndex stored True;

Relative item position inside its logical zone.

This property reorders the item inside its current zone without changing the zone itself. Assigned values are automatically clamped to the valid range of the zone: 0 to zone item count - 1.

Published property GlyphIndex: Integer Read FGlyphIndex Write SetGlyphIndex default -1;

Optional index in the bar global ImageList.

The value -1 means that no image index is assigned.

Published property GlyphPosition: TNoReflowTabBarItemGlyphPosition Read FGlyphPosition Write SetGlyphPosition default nrigpDefault;

Item-specific glyph position.

nrigpDefault uses the global position defined by the bar. Other values force the glyph to the left, right, top or bottom for this item only.

Published property ShowGlyph: Boolean Read FShowGlyph Write SetShowGlyph default True;

Determines whether this item's glyph should be displayed.
