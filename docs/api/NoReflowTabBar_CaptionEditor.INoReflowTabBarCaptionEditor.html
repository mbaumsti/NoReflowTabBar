Unit

NoReflowTabBar_CaptionEditor

Declaration

type INoReflowTabBarCaptionEditor = interface(IInterface)

Description

Minimal interface implemented by an inline caption editor.

The TabBar uses this interface instead of manipulating TEdit directly. The exposed surface is intentionally small: only the operations required by the edit lifecycle are present. This prevents the core component from depending on implementation details of the concrete editor control.

Methods

Public Function GetEditorControl: TWinControl;

Returns the real VCL control used as editor.

The returned control is used by the edit support layer for parenting, positioning, visibility, focus and z-order operations.

Public Function GetEditorText: String;

Returns the current editor text.

Public Procedure SetEditorText(Const AValue: String);

Replaces the current editor text.

Public Procedure SelectAllEditorText;

Selects all editable text, when supported by the concrete control.

Public Procedure AssignEditorEvents( AOnExit: TNotifyEvent; AOnKeyDown: TKeyEvent; AOnKeyPress: TKeyPressEvent);

Connects the events required by the TabBar edit lifecycle.

Public Procedure ClearEditorEvents;

Clears the events previously assigned by AssignEditorEvents.

Public Procedure ApplyEditorBaseSettings( AParentFont: Boolean; AParentColor: Boolean; AStyleElements: TStyleElements; ATabStop: Boolean);

Applies the neutral editor settings shared by all editor types.

Public Procedure ApplyEditorTextOrientation( ATextOrientation: TNoReflowTabBarTextOrientation);

Applies the text orientation selected by the TabBar for the edited item.

The default TEdit implementation intentionally ignores this value because a standard edit control cannot rotate its text. Optional editors, such as the VclRotatedEdit adapter, can translate the direction into their own angle/orientation model.

Public Procedure ApplyEditorTextGeometry( Const AGeometry: TNoReflowTabBarCaptionEditorGeometry);

Applies the explicit text geometry calculated by NoReflowTabBar.

The editor receives a center point, a logical length, a logical thickness and the effective text orientation. It must then convert this neutral geometry to its own positioning model.

Public Procedure AssignEditorFont(AFont: TFont);

Replaces the editor font with the specified font.

Public Procedure AddEditorFontStyle(AStyle: TFontStyles);

Adds the specified style flags to the current editor font.

Public Procedure SetEditorStyleElements(AValue: TStyleElements);

Applies VCL style participation flags to the concrete editor.

Public Procedure SetEditorColors( ABackgroundColor: TColor; ATextColor: TColor);

Applies explicit background and text colors to the editor.
