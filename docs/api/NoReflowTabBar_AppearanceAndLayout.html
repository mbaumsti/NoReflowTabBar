TNoReflowTabBarObjectChangedEvent = Procedure(Sender: TObject) Of Object;

Notification event used by persistent appearance and layout sub-objects.

The owner component handles this event to invalidate layout, palette or painting state without forcing the sub-object to depend directly on the final TNoReflowTabBar class.
