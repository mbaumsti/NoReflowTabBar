Declaration

type TNoReflowTabBarLayoutTabs = class(TPersistent)

Description

Layout settings specific to tab rendering.

This class contains only options that describe tab-specific shape and behaviour: - overlap between consecutive tabs; - first and second slants; - first and second corner radii; - optional closing edge drawing.

Common text, signal, glyph and margin settings remain in TNoReflowTabBarLayout.
